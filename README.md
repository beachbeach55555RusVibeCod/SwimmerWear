# SwimmerWear — сайт + CMS

Лендинг и блочная CMS бренда SWIMMER (речная парка).
Чистый PHP 8 + MySQL, без зависимостей и composer'а. Рассчитано на шаред-хостинг reg.ru.

## Структура

```
/                   корень сайта (DocumentRoot)
├── index.php       фронт: рендер страницы по slug из БД
├── config.php      подключение к БД и хелперы
├── install.php     разовая установка: таблицы + демо-контент  ← удалить после установки
├── .htaccess       роутинг + DirectoryIndex
├── assets/
│   └── style.css   стили фронта
├── admin/          админка
│   ├── login.php / logout.php
│   ├── index.php     страницы
│   ├── blocks.php    блочный редактор
│   ├── products.php  товары + варианты (цвет × размер)
│   ├── media.php     медиатека
│   ├── menu.php      меню шапки/подвала
│   ├── settings.php  контакты, смена пароля
│   ├── inc.php       общий каркас + авторизация
│   └── admin.css
└── uploads/        загруженные файлы (права 755)
```

## Установка на хостинг

1. Залить содержимое репозитория в корень сайта (`/www/<домен>/`).
2. Прописать доступы к БД в `config.php`.
3. Открыть `/install.php`, задать логин и пароль администратора, нажать «Установить».
4. **Удалить `install.php`.**
5. Админка: `/admin/`

## Таблицы

`users`, `pages`, `blocks`, `products`, `variants`, `media`, `product_media`, `menu`, `settings`

## Типы блоков

| Тип | Назначение |
|---|---|
| `hero` | Обложка: заголовок, подзаголовок, кнопка |
| `text` | Заголовок + текст |
| `features` | Три карточки преимуществ |
| `products` | Витрина опубликованных товаров |
| `faq` | Вопрос-ответ |

Блоки хранятся в `blocks.data` как JSON — новый тип добавляется в двух местах:
массив `$types` в `admin/blocks.php` и `switch` в `index.php`.
