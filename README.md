# SwimmerWear — сайт + CMS

Витрина бренда SWIMMER (речная парка) и блочная админка к ней.
Чистый PHP 8 + MySQL, без composer и зависимостей. Рассчитано на шаред-хостинг reg.ru.

Вёрстка витрины — перенос лендинга один в один: шрифт Inter с optical sizing, палитра
хаки/туман/сталь, острые углы. Отличие от лендинга одно: контент берётся из базы,
а не зашит в HTML.

## Структура

```
/                    корень сайта (DocumentRoot)
├── index.php        витрина: собирает страницу из блоков и отдаёт данные в window.SW
├── config.php       доступы к БД и хелперы
├── install.php      разовая установка: таблицы + контент лендинга  ← удалить после установки
├── .htaccess        роутинг + DirectoryIndex
├── inc/
│   ├── blocks.php       рендер каждого типа блока
│   └── membrane.svg.php схема трёхслойной мембраны
├── assets/
│   ├── style.css    стили витрины (из лендинга)
│   ├── app.js       слайдеры, карточка товара, корзина (из лендинга)
│   └── logo.svg · logo-white.svg
├── admin/           админка
│   ├── login.php / logout.php
│   ├── index.php      страницы
│   ├── blocks.php     блочный редактор
│   ├── products.php   товары + варианты (цвет × размер)
│   ├── media.php      медиатека
│   ├── menu.php       меню шапки и подвала
│   ├── settings.php   контакты, палитра, таблица размеров, текст «О бренде», пароль
│   ├── inc.php        каркас и авторизация
│   └── admin.css
└── uploads/         загруженные файлы (права 755)
```

## Установка

1. Залить содержимое репозитория в корень сайта (`/www/<домен>/`).
2. Прописать доступы к БД в `config.php`.
3. Открыть `/install.php`, задать логин и пароль администратора, нажать «Установить».
4. **Удалить `install.php`.**
5. Админка: `/admin/`

Установщик идемпотентен — повторный запуск не дублирует данные.

## Типы блоков

| Тип | Что рисует |
|---|---|
| `hero` | Полноэкранная обложка: слайдер (фото и `.mp4`), заголовок, кнопка, строка характеристик с иконками |
| `products` | Рельс карточек товаров с модалкой выбора цвета и размера |
| `scenarios` | Слайдер сценариев на пол-экрана |
| `tech` | SVG-схема мембраны и список технологий |
| `build` | Текст о конструкции и рельс деталей |
| `kit` | Комплектация: три фото и нумерованный список |
| `faq` | Аккордеон «вопрос — ответ» |
| `reviews` | Отзывы на плашках цвета хаки |
| `text` | Заголовок и абзацы |

Блоки хранятся в `blocks.data` как JSON, переставляются стрелками, скрываются галочкой.
Новый тип добавляется в трёх местах: `$types` в `admin/blocks.php` (форма),
`block_<тип>()` в `inc/blocks.php` (рендер) и ветка сохранения в `admin/blocks.php`.

## Таблицы

`users`, `pages`, `blocks`, `products`, `variants`, `media`, `product_media`, `menu`, `settings`

Товары лежат отдельно от блоков — корзина и оплата подключаются без переделки витрины.
Поле `media.file` принимает и имя файла из `uploads/`, и внешнюю ссылку.

## Настройки, влияющие на витрину

- `colors` — палитра, по строке на цвет: `название|#HEX`. Название должно совпадать с цветом варианта товара, иначе кружок на карточке будет серым.
- `size_table` — таблица размеров, колонки через `|`, первая строка — шапка.
- `product_tags` — плашки характеристик в карточке товара, через запятую.
- `brand_title` / `brand_text` / `brand_image` — окно «О бренде».

## Палитра
